## Hi there 👋

Welcome to **My-TS.org's official GitHub organization!**

We’re a community-driven initiative providing open-source tools to make managing your **TeamSpeak 3 servers easier, safer, and better integrated** with the My-TS.org platform.

---

### 🙋‍♂️ What We Do

We create and maintain tools that help TeamSpeak server owners:

- Register their servers on [My-TS.org](https://my-ts.org)
- Share server info safely using secure wrappers
- Automate tasks like creating permission-limited query groups

All of our projects are open source and free to use!

---

### 🌈 How to Contribute

We love contributions from the community! Here’s how to get started:

1. 🔍 Check out our [repositories](https://github.com/my-ts-org)
2. 🐛 Report bugs or suggest features via issues
3. 👨‍💻 Submit pull requests with improvements

Have an idea that fits our mission? Let’s talk!
