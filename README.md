# My-TS.org Tools

Welcome to the **My-TS.org GitHub organization** — your central hub for tools and scripts designed to integrate and enhance your TeamSpeak 3 server experience with [My-TS.org](https://my-ts.org).

Our goal is to simplify the process of registering your TeamSpeak server and using our platform’s features securely and efficiently.

---

## Available Tools

### [TeamSpeak Query Wrapper](https://github.com/my-ts-org/teamspeak-query-wrapper)

> A secure PHP wrapper for TeamSpeak server owners to **safely gather and share server information** with My-TS.org.

- Written in PHP  
- Acts as a secure middleman between your server and our platform  
- Enables My-TS.org to fetch server data **without exposing sensitive credentials**

### [TeamSpeak Query Creator](https://github.com/my-ts-org/teamspeak-query-creator)

> A **PowerShell script** to automate the creation of **limited-permission server groups** for TeamSpeak 3 servers.

- Designed for use with My-TS.org query login functionality  
- Reduces security risks by creating permission-restricted server groups  
- Easy setup for server owners using Windows
